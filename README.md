# Julián Ahunca — Estudio creativo

Sitio estático listo para GitHub Pages. No requiere compilación, instalación de programas ni terminal.

## Publicar en GitHub Pages

1. Entra a https://github.com e inicia sesión.
2. Pulsa **New repository**.
3. Escribe un nombre, por ejemplo `julian-ahunca-web`.
4. Selecciona **Public** y crea el repositorio.
5. Descomprime el ZIP en tu computador.
6. Dentro de la carpeta descomprimida encontrarás `index.html`, `styles.css`, `script.js` y `assets`.
7. En tu repositorio, pulsa **Add file → Upload files**.
8. Arrastra `index.html`, `styles.css`, `script.js` y la carpeta `assets` (no subas la carpeta contenedora `julian-ahunca-web`; sube su contenido).
9. Pulsa **Commit changes**.
10. Abre **Settings → Pages**.
11. En **Build and deployment**, elige **Deploy from a branch**.
12. En Branch selecciona `main` y carpeta `/ (root)`. Pulsa **Save**.
13. Espera unos minutos. GitHub mostrará la dirección pública de tu web en esa misma sección.

## Actualizar contenido

Para reemplazar una imagen o video, sube el archivo nuevo a `assets` conservando el nombre exacto o actualiza el archivo correspondiente desde GitHub. Los videos de YouTube se cargan al pulsar reproducir para evitar cargar reproductores innecesarios al abrir la página.
